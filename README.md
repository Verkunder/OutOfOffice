# Out Of Office

Personal travel journal for a Pattaya trip: photos, emotions, places, ideas, and notes collected during the vacation.

## Stack

- Next.js App Router
- React
- Ant Design
- Supabase Auth, Database, and Storage

## Setup

1. Copy `.env.example` to `.env.local`.
2. Add `NEXT_PUBLIC_SUPABASE_ANON_KEY` from Supabase Project Settings.
3. Run the SQL in `supabase/schema.sql` in the Supabase SQL editor.
4. Start the app:

```bash
npm run dev
```

The Supabase project URL is already set to `https://gwmcqyrkgtkznmxopsju.supabase.co`.

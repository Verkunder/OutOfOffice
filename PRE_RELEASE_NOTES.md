# Out Of Office pre-release

## Включено в pre-release

- Публичная лента дневника без авторизации.
- Раздел фото.
- Админ-вход через Supabase Auth.
- Создание и редактирование записей только для админа.
- Добавление и удаление фото только для админа.
- Публичное чтение записей и фото из Supabase.
- Мобильная компоновка для ленты, фото, hero-блока и статистики.

## Спрятано до следующей версии

- Раздел "Места".
- Раздел "Идеи".
- Боковые панели мест и идей.
- Прогресс идей в публичной статистике.
- Счетчик мест в публичной статистике.

## Что еще не доделали

- Нормальная загрузка фото в Supabase Storage вместо хранения data-url.
- Удаление файлов из Supabase Storage при удалении фото из записи.
- Публичные страницы отдельных записей с нормальными ссылками.
- Фильтры по дням, тегам и локациям.
- Полировка админки под мобильный экран.
- Состояния пустой ленты, ошибок загрузки и долгой синхронизации.
- Финальный визуальный QA на реальных телефонах.
- Деплой production-версии.
